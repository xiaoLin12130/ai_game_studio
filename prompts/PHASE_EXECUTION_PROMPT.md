# 阶段执行提示词模板

你现在执行 `{PHASE_ID}`。先读取 `AGENTS.md`、阶段文件、当前 `state/project_state.json`、`state/memory.json`、最近的 `memory-bank/handoff.md` 和关联任务契约。

开始前：
1. 检查 Git 工作区、当前分支、远端和上阶段复审状态。
2. 确认上阶段状态为 `APPROVED` 或 `APPROVED_WITH_ACTIONS` 且修正已完成。
3. 核对本阶段目标、输入、禁止项、依赖和验收标准。
4. 列出本阶段执行计划和风险；不得扩大范围。

执行中：
- 按任务契约小步实施；写入前检查锚点唯一；写后回读和查看 diff。
- AI 推理通过 DSH；Studio 确定性逻辑由代码完成。
- 不允许 Mock 冒充真实能力。
- 失败、未跑、阻塞要明确记录，不可吞掉。
- 每个可独立验收任务完成后更新状态和证据。

结束时：
1. 对照阶段文件逐项验收。
2. 跑所有测试并保留原始输出。
3. 更新项目状态、memory、handoff、阶段报告和复审交接。
4. 安全扫描后提交并推送阶段分支。
5. 报告远端 URL、branch、完整 SHA、结果和未决风险。
6. **停止，不要执行下一阶段，等待外部复审。**
