# 已确认决策

- 产品定位：AI 游戏研发顾问 + 自动化开发平台。
- AI Runtime：统一使用 DSH 官方 SDK；不自建模型通信/Agent Runtime。
- 用户可以随时讨论，但只有批准的正式基线驱动开发。
- 工作区分为需求讨论、正式研发、需求变更。
- 素材库采用全局共享 + 项目专属，支持两种导入入口。
- 需求变更必须先影响分析、用户审批，再更新基线和局部返工。
- 首轮环境以 Windows 本地单用户、Cocos Creator 3.8.6、微信小游戏为目标。
- 不包含发布后的运营监控、持续顾问和自动迭代。
- 每个开发阶段完成后推 GitHub，等待外部复审通过再继续。
