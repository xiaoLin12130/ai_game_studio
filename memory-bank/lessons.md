# 经验教训

## 开发安全

- 先读后改，锚点必须唯一；写后回读并查看 diff。
- 同一工程同一时间只允许一个写入任务；构建独占。
- 测试脚本失败必须非零退出；测试脚本本身也要做校验。

## 证据

- 构建成功码不等于产物正确/新鲜。
- 真实运行证据必须关联 Commit、Build ID、时间戳和环境。
- Web/Mock/开发者工具不能替代真机；未验证必须明确标记。
- 夹具截图必须标 `[FIXTURE]`。

## 素材/UI

- 原始素材只读，派生版本保留来源。
- 先盘点素材和缺失，再设计页面，不允许随意拼素材。
- HTML 原型不能替代目标引擎内的布局和运行验证。
