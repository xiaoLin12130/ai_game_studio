# PHASE 01｜应用基础、项目空间与可靠状态

## 目标

建立可运行的本地应用基础，以及项目、数据、状态、文件安全、事件和导航骨架。此阶段不追求大量业务功能，先让后续所有模块有可靠落点。

## 工作项

- 按 PHASE 00 ADR 落地 Windows 本地单用户应用架构。
- 建立一级导航：工作台、游戏项目、AI 顾问、设计与素材、决策中心。
- 实现创建/打开/关闭项目，项目路径、引擎和目标平台配置。
- 实现本地持久化、迁移机制、备份/恢复基础能力。
- 建立 Project/Event/Approval/Task 等核心数据模型初版。
- 建立项目根路径隔离、路径穿越保护、项目写锁和构建锁基础设施。
- 建立日志、错误边界、诊断页和环境检测页。
- 把现有 `AGENTS.md`、`docs/`、`memory-bank/`、`state/` 规则整合为可读取的项目规则入口。
- 展示真实 DSH 连接状态；未连接要显示未连接，不能假装可用。

## 验收门禁

- [ ] 应用可在目标 Windows 环境启动。
- [ ] 能创建、重开、关闭项目并保持数据。
- [ ] 两个项目之间数据/路径隔离。
- [ ] 写锁能阻止第二个写入任务进入。
- [ ] 构建锁有独立状态和测试。
- [ ] 数据迁移/备份/恢复至少有自动化测试。
- [ ] 错误提示有可执行恢复方向。
- [ ] 五个一级入口结构稳定，普通/高级信息层次清楚。
- [ ] 阶段报告、证据和 GitHub 推送完成。

## 不做

不在此阶段接入复杂 RAG、完整素材识别、大规模任务调度或多引擎支持。
