# PHASE 03｜游戏设计、项目初始化与素材智能管理

## 目标

把批准的游戏方向变成结构化可执行设计，并建立全局/项目素材管理及素材缺失分析能力。

## 工作项

- 游戏项目初始化向导：项目目录、目标引擎/平台、分辨率、命名规则、开发环境检查。
- 第一适配路径为 Cocos Creator 3.8.6 + 微信小游戏；真实环境能力检测。
- GDD 拆成玩法、战斗、成长、敌人、数值、页面、音频、存档、平台约束等可追溯设计产物。
- 全局素材库、全局 Inbox、项目素材库、原始区和派生区。
- 素材元数据、hash 去重、尺寸/帧数/格式分析、标签、来源、许可证状态。
- 素材分类建议调用 DSH；确定性属性由程序测量。
- 素材与游戏实体/动作/页面/技能建立匹配关系。
- 自动生成素材盘点报告、缺失清单和替代方案比较。
- 原始素材只读；所有处理和导入操作保留来源及派生关系。
- 用户可以确认素材用途、许可和替代方案。

## 验收门禁

- [ ] 两种导入路径均可用：当前项目 / 全局 Inbox。
- [ ] 素材去重、基础元数据和来源记录可靠。
- [ ] 原始文件不可被派生处理覆盖。
- [ ] 许可未知有明确警告，不默认商用。
- [ ] 素材盘点可导出。
- [ ] AI 分类建议可以编辑和确认。
- [ ] 素材缺失分析能关联游戏实体与页面需求。
- [ ] Cocos 工程初始化检查真实可复现。
- [ ] 阶段报告、证据和 GitHub 推送完成。
