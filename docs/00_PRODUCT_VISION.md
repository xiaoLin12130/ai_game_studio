# 00｜产品愿景与成功标准

## 一句话定位

**AI Game Studio 是面向个人开发者和小团队的 AI 游戏研发顾问与自动化开发平台。** 用户负责想法、方向和关键决策；Studio 管理研发项目、任务、素材、权限、质量与交付；DeepSeek Harness（DSH）统一执行所有 AI 理解、推理、规划和生成工作。

## 目标用户

第一阶段以有一定游戏开发经验、但不擅长完整产品设计/美术规划/质量流程的个人开发者为核心。用户可能熟悉 Cocos、微信小游戏和 DSH，但不希望自己管理一堆 Agent、Session、Prompt 和测试脚本。

## 用户真正要完成的事情

从一个模糊想法出发，经过讨论、研究、设计、素材准备、原型验证、开发、测试和发布准备，最终获得一款经过证据验收、可交付的游戏。

## 产品承诺

1. 用户不必自己先写完整需求书，可以自然语言开始。
2. 顾问会追问关键缺口、分析可行性、研究竞品并给出可选方案。
3. 用户批准的想法才成为正式基线。
4. 素材先盘点、归类、追踪，再用于设计和开发；不允许 Agent 随意拼图。
5. 页面先完成参考研究、规格和预览，再进入引擎实现。
6. 开发过程按任务和阶段推进，任务有边界、有验收、有证据。
7. DSH 是唯一 AI Runtime，用户不需要复制粘贴 Prompt 到另一个工具。
8. 构建、测试和平台证据可信；不能用“命令成功”冒充“游戏可运行”。
9. 需求变更先分析影响，获批后再局部返工。
10. 每个阶段都能通过 Git 提交回看、复审和回滚。

## 成功标准

- 新用户能从空想法创建项目，不需要先理解内部 Agent 架构。
- 用户能在一个界面内与 DSH 顾问对话、查看执行状态和处理审批。
- 正式基线、讨论草稿和变更请求严格分离。
- 每条正式需求都能追溯到设计、任务、测试和证据。
- 素材有来源、标签、用途、许可状态、尺寸和项目使用关系。
- 一个项目只有一个写入执行者；构建独占；失败可恢复。
- 阶段验收有自动化结果和人工/平台验证状态。
- 最终能导出源工程、发布候选包、构建信息、测试证据和交付说明。

## 不以此作为成功指标

- Agent 数量越多越好。
- 所有步骤都完全无人值守。
- UI 上显示一个百分比就代表真实进度。
- 模型生成的长文档数量。
- 未经用户批准自动扩展功能。
